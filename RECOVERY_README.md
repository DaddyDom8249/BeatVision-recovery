# BeatVision recovered GitHub-ready baseline

This package is a cleaned copy of the BeatVision Phase 4A fixed codebase available in the ChatGPT project archive.

It intentionally excludes platform metadata, archives, large media outputs, dependency folders, and build artifacts.

Important: this is a recovered baseline, not a claim that it is the newest Replit export. The archive diagnostics in the project history identify a newer TRUE_COMPLETE export, but its raw ZIP is not currently available as a materialized file in this workspace.

## Frontend

The frontend is the existing BeatVision React application. It uses browser persistence and contains the project workflow, world report, storyboard, scene image, provider, and motion/export components.

## Safety

No `.env` secrets or JWT-style Supabase keys were found in the copied source during this recovery pass.
